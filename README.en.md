# Ubers
A web application developed to consolidate advanced structuring concepts with HTML5, styling and complex layouts with CSS3 (Flexbox, CSS Grid, Pseudo-elements, Glassmorphism), dynamic element manipulation via TypeScript, with a PHP backend.

## 🛠️ Technologies Used

The project was built using core web technologies:

| Technology| Role in Project |
| :--- | :--- |
| **HTML5** | Page element structuring and game containers. |
| **PHP** | Dynamic rendering of player data, modular template loading, and backend state management. |
| **CSS3** | Visual styling, color schemes, positioning, and responsiveness. |
| **JavaScript** | Core game logic, movement, and interactivity. |
| **TypeScript** | Static typing and tactical system logic organization, safely manipulating the DOM with better autocomplete during development. |
